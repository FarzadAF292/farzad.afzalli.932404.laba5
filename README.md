## Описание

В данной лабораторной работе была продолжена разработка страницы из предыдущих лабораторных работ.

Основная цель работы — изучение DOM, взаимодействие с элементами страницы и сохранение состояния с помощью `localStorage`.

## Реализовано

В работе реализованы:

- поиск элементов через `getElementById`;
- поиск элементов через `querySelector`;
- поиск элементов через `querySelectorAll`;
- создание новых элементов через `document.createElement`;
- добавление элементов через `appendChild`;
- удаление элементов из DOM;
- динамическое добавление новых startup-идей;
- удаление отдельной идеи;
- удаление последней идеи;
- скрытие и показ блока с идеями;
- переключение светлой и тёмной темы;
- изменение текста кнопок;
- изменение CSS-классов через `classList`;
- проверка существования элементов перед работой с ними;
- вывод ошибок через `console.error`;
- сохранение startup-идей в `localStorage`;
- сохранение выбранной темы в `localStorage`;
- восстановление данных после перезагрузки страницы.

## Вариант 16

Для каждой startup-идеи используются следующие данные:

- название идеи;
- целевая аудитория;
- ключевая метрика;
- кнопка удаления.

Для управления идеями используются кнопки:

- `Add Idea`;
- `Delete Last`;
- `Hide Ideas / Show Ideas`;
- `Toggle Theme`.

## localStorage

С помощью `localStorage` сохраняются:

- добавленные идеи;
- удалённые идеи;
- выбранная тема страницы.

После перезагрузки страницы сохранённое состояние автоматически восстанавливается.
